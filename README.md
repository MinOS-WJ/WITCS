# WITCS

**WITCS** = **W**uhan **I**nstitute of **T**echnology **C**omputer **S**cience Resources Database

> 一个面向武汉工程大学计算机科学与技术及相关专业的课程资源、学习资料、项目代码与经验分享的集中式数据库。

## 📚 仓库简介

WITCS 致力于收集、整理和分享武汉工程大学计算机科学领域的优质学习资源，包括但不限于：

- 课程笔记与讲义
- 实验指导与报告模板
- 历年试题与复习资料
- 课程设计、大作业参考代码
- 考研、竞赛、实习经验分享

我们希望这个仓库能成为 WIT 计科学子的“知识后花园”，减少重复搜集信息的时间，帮助每一位同学更高效地学习与成长。
